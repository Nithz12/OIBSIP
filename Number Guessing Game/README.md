# Number Guessing Game

## 📌 Project Overview

The Number Guessing Game is a Java console application developed as part of the Oasis Infobyte Java Development Internship.

The game generates a random number based on the selected difficulty level. The player has a limited number of attempts to guess the correct number. After every guess, the program provides hints indicating whether the guess is too high or too low. The game also supports multiple rounds.

---

## 🎯 Objective

Develop a Java application that demonstrates the use of loops, conditional statements, random number generation, user input handling, and basic game logic.

---

## ✨ Features

- Difficulty Levels
  - Easy (1–50, 10 attempts)
  - Medium (1–100, 7 attempts)
  - Hard (1–200, 5 attempts)
- Random number generation
- User-friendly console interface
- Too High / Too Low hints
- Attempt counter
- Maximum attempt limit
- Win/Lose messages
- Round summary
- Play Again option

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Compile the Java file.

```
javac NumberGuessingGame.java
```

3. Run the program.

```
java NumberGuessingGame
```

4. Select the difficulty level.
5. Guess the number within the allowed attempts.
6. Choose whether to play another round.
